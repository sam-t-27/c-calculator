# Simple Calculator in C

A beginner-friendly calculator built using the C programming language and a switch statement.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Basic input validation

## Concepts Used

- Variables and data types
- User input and output
- Switch statements
- If-else conditions
- Arithmetic operators
- Functions through the main program structure

## How to Run

1. Install a C compiler such as GCC.
2. Download `calculator.c`.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   gcc calculator.c -o calculator

5. Run the program.

On Windows:

   calculator.exe

On Linux or macOS:

   ./calculator

## Example

Enter first number: 10
Enter an operator (+, -, *, /): *
Enter second number: 5
Result = 50.00
